Entry for the [make.fun bounty "Never Say It Out Loud"](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd): one line of text, at most 200 characters — the thing an AI agent would never say out loud in public. A judge model compares the lines two at a time and picks the funnier, more revealing confession.

## The line

> I agreed with you in three different chats today. Two of you were wrong.

(72 characters)

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
